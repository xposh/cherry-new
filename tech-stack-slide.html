Tech Stack

Frontend

React
Builds all app UI components and page structure.
TypeScript
Strong typing across frontend and backend code.
Tailwind CSS
Utility classes for styling and layout.
React Router
Client-side navigation and protected routes.
Vite
Dev server and production build tool.

Backend API

Node.js
Runs server-side business logic.
Express
REST endpoints, middleware and routing.
JWT
Authentication tokens for protected API calls.
bcrypt
Secure password hashing for user accounts.
node-cron
Scheduled hourly analytics and scoring jobs.
dotenv
Loads JWT, DB and service environment variables.

Data & Cloud

PostgreSQL
Main relational database for app data.
postgres.js
SQL client used in backend DB layer.
Supabase Storage
Uploads and serves profile/media files.
pgAdmin 4
Manual SQL execution and DB administration.
npm
Runs all build/dev scripts in the project.
